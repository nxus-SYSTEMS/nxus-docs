## Denied Public Wording

The following wording classes are denied for routed public docs, public sync,
generated public docs, Website copy, release notes, product catalog copy,
provider registry, package metadata, public schema/API surfaces, and customer
support/compliance materials until a later explicit gate opens them:

- runtime discovery execution;
- DataFusion runtime availability;
- public API/schema/CLI/wrapper;
- provider registry;
- CE/OSS deep discovery;
- support/compliance/security guarantees;
- production-ready overclaims;
- Product Catalog/Odoo grant claims;
- DataFusion gateway execution, Arrow runtime, SQL execution, query execution,
  reverse table-provider execution, or runtime table-provider execution;
- callback, webhook, managed queue, async dispatch, or runtime-provider
  publication;
- inline SQL, inline plan bodies, inline rows, Arrow batches, live handles,
  materialization, data-plane payloads, customer records, or private topology;
- public release/package/tag/changelog/deploy readiness;
- D10 expansion beyond external PlanRef-only posture;
- C ABI bridge as a full public C SDK;
- Go discovery parity as fully implemented unless later evidence proves it;
- discovery entitlement domains as customer-visible SKUs, feature grants,
  support terms, compliance terms, SEO metadata, structured data, sitemap data,
  or public pricing copy.
