# Safe Extension Authoring Fixture

`hello-provider` is an `extension_authoring` example for SDK extension
authorship using a deterministic local fixture. It does not perform network
calls, require credentials, use provider accounts, claim provider registry
status, or promise platform expansion.

RRE, Prolog/Scryer, Cedar, Pydantic v2, TypeScript/Zod, and Node wrapper
preview remain private/static planning evidence unless a later hard gate
supplies authority.
