# Safe Denial Vocabulary Fixture

Non-`Passed` projection rows remain non-emitted and do not authorize public
docs, release notes, package work, provider registry entries, generated
artifacts, wrapper/API readiness, or downstream emission.

Forbidden fragments such as `public-docs`, `docs-allowed`,
`downstream-emission`, `provider-registry`, `package-publication`, `npm-ready`,
`release-ready`, `public-ready`, and `generated-artifact` appear here only as
quoted denied scan vocabulary in a private helper fixture.

Licensed-private, research, experimental, preview, unsupported,
validation-pending, denied, stale, downgraded, and blocked-by-cap rows stay
bounded as private planning evidence.
